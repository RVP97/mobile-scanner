카메라를 비추기만 하면 Lunet이 코드가 무엇인지, 실제로 어디로 연결되는지, 다음에 무엇을 하면 되는지 알려 줍니다. 안전하게 쓰는 QR코드 스캐너이자 바코드 리더기. 계정도, 광고도, 추적도 없습니다.

탭하기 전에 먼저 검사
QR코드 피싱(큐싱)이 급증하고 있습니다. 주차 정산기 위에 덧붙인 스티커, 가짜 메뉴판, '택배 부재 안내' 전단지까지. Lunet은 무엇이든 열리기 전에 모든 링크를 검사합니다.
- 리디렉션을 끝까지 따라가 안내판에 적힌 주소가 아닌 실제 목적지를 표시
- northbank.com을 사칭하는 n0rthbank.com 같은 유사 도메인 탐지
- 갓 등록된 도메인, 숨겨진 @ 속임수, 단축 URL, 보안되지 않은 페이지 경고
- 안전, 주의, 위험 중 하나로 명확하게 판정하고 이유를 쉬운 말로 설명
- 위험한 코드는 '열지 않기'가 기본값

코드마다 알맞은 동작
QR, EAN, UPC, Code 128, PDF417, Aztec, Data Matrix 등 19가지 형식을 인식하고, 각 코드가 어디에 쓰이는지 알아서 판단합니다.
- Wi-Fi: 탭 한 번으로 네트워크에 연결
- 탑승권: Apple 지갑이나 캘린더에 추가
- 연락처와 일정: iPhone에 바로 저장
- 상품: 성분과 상세 정보 조회
- 택배: 배송 조회
- 이메일, 메시지, 지도, 암호화폐 주소도 각각 알맞게 처리
사진과 스크린샷 속 코드도 스캔하고, 멀티 스캔으로 여러 코드를 한 번에 인식하세요.

자주 쓰는 코드를 탭 한 번에
집 Wi-Fi, 내 연락처 카드, 다가오는 탑승권을 Wallet 스타일 카드로 홈에 보관하세요. 탭 한 번이면 최대 밝기의 전체 화면으로 코드를 보여 주어, 탑승구에서도 친구의 휴대폰 앞에서도 바로 쓸 수 있습니다.
기록에는 스캔한 모든 코드가 남고 검색, 필터, 고정을 지원합니다. Face ID로 잠그고 CSV로 내보낼 수 있으며, 원하면 각 코드를 스캔한 위치도 확인할 수 있습니다.

아름다운 코드 만들기
Wi-Fi, 링크, 연락처, 텍스트, 이메일, SMS, 전화, 일정, 위치용 코드와 15가지 규격의 상품 바코드를 만들 수 있습니다. Studio에서 점, 모서리, 색상, 그라디언트, 로고, 프레임으로 QR코드를 꾸미면, Lunet이 기기에서 직접 디자인이 제대로 스캔되는지 확인합니다.

언제든 손 닿는 곳에
제어 센터, 잠금 화면, 동작 버튼, 위젯, Siri에서 바로 스캔을 시작하세요. 멀티 스캔 진행 상황은 실시간 현황으로 표시되고, 단축어로 어떤 이미지 속 코드든 스캔할 수 있습니다.

처음부터 프라이버시를 생각한 설계
스캔 기록은 기기 밖으로 나가지 않습니다. Lunet은 꼭 필요할 때만 인터넷에 연결합니다. 링크를 해당 링크의 서버에서 확인할 때, Open Food Facts에서 상품을 조회할 때, Apple 지갑에 추가하는 패스에 서명할 때뿐입니다. 아무것도 저장하지 않고, 아무것도 추적하지 않습니다.

iPhone과 iPad를 위해 네이티브로 만들었으며 Liquid Glass, 라이트 및 다크 모드, Dynamic Type, VoiceOver를 지원합니다.
